二、三档方案（按算力与目标选择）

BASELINE · 必做保底

DenseNet121 / ResNet50

  • ImageNet 预训练，224 输入
  • BCEWithLogits 损失
  • 跑通训练→验证→打包全链路
参考 mAUC ≈ 0.80–0.83
主力 · 推荐冲奖

ConvNeXt-T / Swin-T / EfficientNetV2

  • 320 输入，ASL 损失 + 阳性率权重
  • EMA + 每类阈值 + 翻转 TTA
  • 5 折 × 2–3 个异构 backbone 集成
参考 mAUC ≈ 0.84–0.87
进阶 · 冲前三

医学预训练 + 高分辨率

  • RadImageNet / BioViL 领域权重
  • 384 微调、知识蒸馏
  • 域随机化增强提升跨设备鲁棒性
参考 mAUC ≈ 0.87+

三、提分杠杆（按性价比从高到低）

1
严格按患者划分训练/验证同一患者片子整体进同一折，杜绝指标虚高
前提性，不做全崩
2
长尾损失 ASL / 加权 BCE压制海量易负样本，救稀有病类别
稀有类 AUC +2~5
3
每类阈值搜索验证集上逐类选最优阈值（影响 F1，不影响 AUC）
macro-F1 +2~5
4
EMA + 水平翻转 TTA权重滑动平均 + 测试时增强，几乎无风险
+0.3~0.8
5
异构模型概率平均集成CNN 与 Transformer 错误互补
+0.5~1.0
6
分辨率 224→320/384 微调结节/纤维化等小目标纹理收益明显
小结节类 +1~3
7
医学领域预训练权重用放射影像预训练替换 ImageNet 权重
+0.3~1.0

五、提交硬约束（往届规程，今年以官方为准）

✔ 必须做到

  • zip 内固定结构：run.py + requirements.txt + 权重 + 代码
  • 权重本地加载（pretrained=False），断网可跑
  • 权重+代码总体积 ≤ 2GB，依赖锁版本兼容 Python 3.8
  • 损坏图/单通道/16 位图有兜底，体现鲁棒性
  • 用预训练权重须有自己的训练/改进工作量并写进报告

✘ 禁止 / 易踩坑

  • 禁止联网 API 大模型、禁止测试集信息泄漏
  • 不要用 softmax + 单分类交叉熵（任务是多标签）
  • 不要随机按图片划分（必须按患者分组）
  • 不要拿每天仅 1 次的提交机会做调试
  • 不要只看总分，务必看每类 AUC（长尾类定胜负）
说明：mAUC 数值为 ChestX-ray14 公开基准上的参考区间，实际取决于官方数据与划分；指标口径（mAUC/mAP/F1）与提交接口以 10-15 官方发布的赛题说明和 submit_example 为准。
